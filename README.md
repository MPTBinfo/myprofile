# Professional Profile Redirect

Static redirect page to the linked Blinq professional profile.

## Behavior

Open `index.html` in a browser. The page redirects to the configured Blinq profile and includes a manual link if automatic redirect is unavailable.

## Maintenance

- Confirm that the destination profile is still correct before changing the redirect.
- The destination is an external third-party profile; its availability and privacy settings are controlled by that provider.
